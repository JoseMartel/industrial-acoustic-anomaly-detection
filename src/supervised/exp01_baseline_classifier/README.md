# Experimento 01: Classificador Supervisionado (Baseline)

## Descrição
Este diretório está reservado para a implementação de um classificador binário supervisionado. Diferente do Autoencoder, este modelo terá acesso às labels "Normal" e "Anormal" durante o treinamento.

## Objetivos
- Estabelecer um "Upper Bound" de performance usando labels.
- Comparar se a mesma arquitetura do Encoder treinada do zero é capaz de classificação simples e avaliar sua robustez.
